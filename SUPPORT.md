# Support

## Usage And Setup Help

Search the [documentation](./docs/README.md), [FAQ](./docs/faq/README.md), and existing [issues](https://github.com/mickpletcher/paper-trade-local-lab/issues) first. If the problem remains, open an issue and include:

* operating system and Python version
* TradeForge commit or release version
* the command that failed
* the smallest reproducible example
* sanitized logs or traceback output

## Feature Requests

Use the feature-request issue form. Describe the research problem and expected behavior, and keep proposals within the local paper-trading boundary.

## Security Reports

Follow [SECURITY.md](./SECURITY.md). Never place a vulnerability, credential, or private data in a public issue.

## Scope

Community support is best effort. TradeForge is research software, not financial advice, a brokerage service, or a live-trading platform.
