# Naming Standards

## File Names

* use lower case kebab case for Markdown files
* use `README.md` only for section entry points
* avoid catch all file names such as `notes.md` or `stuff.md`

## Section Patterns

* references use `reference`
* rules use `policy`
* repeatable task flows use `workflow` or `playbook`
* strategic plans use `roadmap` or `readiness`
* exploratory notes belong in the Wiki, not `docs/`

## Heading Standards

* use stable headings
* keep the first heading equal to the file title
* keep major headings consistent across sibling docs

## Link Standards

* use relative links inside the repo
* link to the canonical doc, not to copied text
* keep anchors predictable by using clear headings

## AI Retrieval Standards

* prefer specific nouns in file names
* include domain terms in the first paragraph
* keep unrelated topics out of the same file
