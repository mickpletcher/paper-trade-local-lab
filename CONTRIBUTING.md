# Contributing

TradeForge uses a layered documentation model.

Start here:

* [docs/contributing/README.md](./docs/contributing/README.md)
* [docs/contributing/documentation-governance.md](./docs/contributing/documentation-governance.md)
* [docs/contributing/wiki-strategy.md](./docs/contributing/wiki-strategy.md)

Before opening a pull request:

1. update the canonical doc when behavior changes
2. keep README changes short and link to deeper docs
3. keep exploratory notes in the Wiki until they become durable
4. run the repo validation workflows that apply to your change
