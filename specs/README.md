# Specs

This folder holds numbered GitHub Spec packages for non trivial TradeForge work.

Use one numbered folder per feature or workstream.

Recommended flow:

1. Create the next numbered folder.
2. Write `requirements.md`.
3. Write `spec.md`.
4. Write `plan.md`.
5. Write `tasks.md`.
6. Implement the work.
7. Write `audit.md` if the change was substantial.
8. Add `release-readiness.md` if the change affects local operators or deployment.

Current baseline package:

* `001-core-trading-foundation`
* `002-live-market-data-valuation`
* `003-execution-correctness`
