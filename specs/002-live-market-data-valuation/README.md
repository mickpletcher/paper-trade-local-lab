# 002 Live Market Data Valuation

This package defines how TradeForge can consume live market data for valuation while keeping all trading logic local.

The intent is to mark positions to market in near real time without introducing live brokerage execution.

Files in this package:

* `requirements.md`
* `spec.md`
* `plan.md`
* `tasks.md`
* `implementation-guide.md`
* `feed-options.md`
